Methodology

  • Setup. Headless retrace exec, 5 fresh single-purpose repos, reasoning off, run cache-cold to remove ordering bias.
  • Model. Qwen-3.6-27B class, served through the Retrace gateway with prefix caching enabled.
  • Tuning. Two changes — a cache-busting prefix token removed (cache), and the loop no longer re-requests an answer the model already produced (round-trips). Nothing else varied.
  • Honesty. Internal benchmark on one model and workload; real throughput depends on model, hardware, and task.
